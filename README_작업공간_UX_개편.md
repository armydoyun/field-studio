# 작업공간 UI/UX 개편

2026-10-15. 이 문서가 최신 작업공간 동작 기준입니다. 이전 README의 화면 배치·라벨·기본 높이·bool 추가 폼 설명은 과거 버전 기록입니다.

## 개선 방향

실행 결과와 편집본을 혼동하지 않게 만들고, 자주 쓰는 도구에는 바로 접근하면서 드물게 쓰는 도구는 접어 둘 수 있게 했습니다. 기존 textarea·Renderer·프로젝트 저장/검증 경로를 사용하며 새로운 실행 모듈과 외부 라이브러리는 추가하지 않았습니다.

## 적용한 개선

| 영역 | 변경 내용 |
| --- | --- |
| 화면 계층 | 패널 제목·여백·타이포그래피 정리, 버튼·표면·포커스 색상 일관성 보강, 작은 화면의 상태 정보 밀도 조정 |
| 작품 표시 | 캔버스를 덮던 장식용 명암 오버레이 제거. 실제 셰이더 색을 UI 효과로 변형하지 않음 |
| 프로젝트 도구 | 입력 채널·프로젝트 파일·시작 예제·이미지·패스 연결·픽셀 검사를 네이티브 details로 분리 |
| 도구 공간 | 도구 영역 전체 표시/숨기기. 숨긴 뒤 남는 빈 Grid 열/행 제거 |
| 배치 기억 | 도구 표시 여부와 각 도구 그룹/코드 보조 도구의 접힘 상태를 브라우저에 저장. 잘못된 저장값은 무시 |
| 편집 도구 | 검색·치환·줄 이동·함수 탐색·자동 완성은 상시 표시. GLSL 파일/샘플/표시 설정은 별도 접힘 영역으로 정리 |
| 편집 상태 | 적용됨 / 미적용 변경 / 오류 확인을 별도 배지로 표시. 일반 파일 작업 오류는 정상 적용된 코드 상태와 구분 |
| 실행 결과 | 미적용 변경 또는 컴파일 실패 시 화면이 마지막 성공 결과라는 안내 표시 |
| 재생 조작 | 편집기를 열지 않아도 재생/일시정지 가능. 뷰포트에 포커스가 있으면 Space로 조작 |
| 상태 정합성 | 재생 중/일시정지를 실제 Renderer 상태로 표시. 편집기와 뷰포트의 재생 명령은 Studio 한 경로를 공유 |
| 집중 모드 | 기존 미리보기 일시정지 동작 유지. 집중 모드의 재생 버튼은 '복귀 시 재생/정지'로 예약 상태를 명확히 표시 |
| 출력 복귀 | Buffer 편집 상태를 유지하면서 최종 Image로 바로 복귀하는 버튼 제공 |
| 패스 전환 | 패스별 선택 범위·커서·가로/세로 스크롤을 메모리에 보존. 소스가 달라졌으면 오래된 위치를 복원하지 않음 |
| 오류 수정 | 진단에 패스 이름과 줄 번호 표시. 진단 클릭 시 해당 패스를 선택하고 원본 줄로 이동. 새 편집 시작 시 오래된 줄 진단 제거 |
| 버퍼 액션 | Image에서는 해당하지 않는 버퍼 도구를 숨기고 픽셀 검사를 비활성화. 8개 버퍼 한도에서 추가 버튼 비활성화 |
| 채널 문맥 | 입력 채널 제목에 현재 선택한 패스 표시, current/previous 의미 안내 |
| 파일 저장 | Pack을 우선 표시하고 코드·파라미터·연결 이미지·설정 포함 범위를 설명. 소스 JSON과 단일 GLSL의 범위를 분리 |
| 파일 처리 | Pack 입출력·이미지/GLSL 불러오기에 처리 중 문구와 aria-busy 표시. 성공/실패 후 버튼과 원래 라벨 복구. 반복 처리는 공통 함수 사용 |
| 파라미터 작업 | 데스크톱에서는 편집기를 유지한 채 파라미터 패널 열기. 좁은 화면에서는 편집기를 닫아 패널 공간 확보 |
| bool 생성 | 초기 값을 true/false 선택으로 입력. 숨겨진 숫자 입력은 required 검증에서 제외 |
| 추가 폼 | 열 때 이름 입력에 포커스, 취소 시 입력 초안은 유지하고 추가 버튼으로 포커스 복귀 |
| 파라미터 오류 | 추가 폼이 닫혀 있어도 오류를 볼 수 있도록 오류 영역 이동. 화면 오류 알림에 닫기 버튼 제공 |
| 패널 탐색 | 설정 탭마다 스크롤 위치를 유지 |
| 모바일 패널 | 배경 클릭으로 닫기, 열려 있는 동안 뒤의 Stage는 inert로 입력 차단. 편집기 열기/닫기 및 크기 변경 시 상태 동기화 |
| 편집기 높이 | 좁거나 낮은 화면의 기본 높이는 75%, 나머지는 55%. 기존 저장 높이는 우선 적용. CSS가 저장/드래그 높이를 덮어쓰던 충돌 제거 |
| 크기 조절 | ↑↓ 외에 Home/End 지원, 두 번 클릭해 환경별 기본 높이 복원. 포인터 캡처 손실 시 조절 중단, 높이 0인 영역은 무시 |
| 코드 표시 정합성 | 줄 번호와 코드의 행 높이를 1.65로 통일. Tab 2/4 설정을 실제 탭 문자와 강조 레이어 양쪽에 반영 |
| 접근성 | 패스 탭과 편집기의 ARIA 연결, 키보드 포커스 복귀, 강제 색상 모드의 코드 가독성 보강. 같은 상태 문구를 반복 갱신하지 않아 불필요한 알림 감소 |
| 경계 입력 | 빈 FPS/픽셀 제한 입력이 0으로 자동 적용되지 않게 검증. 이미지 목록의 빈 상태 안내 추가 |

## 범위와 의도적으로 추가하지 않은 것

- GLSL 파서/타입 추론 없이 신뢰하기 어려운 '미사용 Uniform 자동 제거', vec3/vec4를 색상으로 단정하는 색상 편집기, 의미 기반 자동 완성 확장은 추가하지 않았습니다.
- 일관된 textarea 편집을 해치는 코드 접기는 추가하지 않았습니다.
- GPU 실행 시간 측정·자동 셰이더 최적화·벤치마크 기반 자동 품질 설정은 추가하지 않았습니다. FPS는 GPU 실행 시간이라고 표시하지 않습니다.
- 클라우드 동기화, 파일 원본 자동 덮어쓰기, 오디오/영상 입력, 타임라인·영상 내보내기 등 현재 기반이 없는 기능은 추가하지 않았습니다.
- 기본 파일 저장은 기존 다운로드 방식입니다. 브라우저가 실제 디스크에 저장했는지는 앱이 확인하지 못하므로 완료 문구는 '내보냄'으로 표시합니다.

Pack은 현재 프로젝트에서 연결한 이미지 원본을 포함합니다. 미연결 이미지까지 전부 백업하지는 않습니다. 패스별 커서와 설정 탭 스크롤은 현재 세션에서만 유지합니다. 그룹 접힘 상태·편집기 높이·기존 글꼴/줄바꿈/들여쓰기 설정은 브라우저 저장소를 사용합니다.

## 코드 구조

실행 파일은 기존 13개 그대로입니다. 변경 파일은 `index.html`, `style.css`, `js/studio.js`, `js/ui.js`, `js/code-editor.js`, `js/settings.js`입니다. UI 상태·포커스·표시는 UI/Studio가, 실제 재생/GPU 자원은 Renderer가 계속 소유합니다. 범용 액션 레지스트리나 새 컴포넌트 계층은 만들지 않았습니다. 파일 처리의 중복된 버튼 상태/오류 복구만 공통화했고, 사라진 화면 구조의 CSS는 제거했습니다.

## 검증과 남은 확인

- `tests/workspace-ux-regression.js`: 실제 모듈과 모의 DOM/WebGL로 25개 동작 검사. 편집/적용/실패 상태, 커서 복원, 재생, 집중 모드, 출력 복귀, 레이아웃 상태, 모바일 입력 차단/해제, bool 생성, 파일 처리 복구 등.
- `tests/workspace-layout-regression.js`: HTML 중첩·고유 ID·도구 소속·CSS 괄호 및 기존 스타일 충돌 검사. 이것은 화면 렌더링 검사가 아닙니다.
- `tests/pair-nesting-regression.js`: 기존 괄호 검사에 들여쓰기 표시 동기화 검사를 포함하여 13개.
- 기존 Node 회귀 검사를 포함한 18개 스위트, JavaScript/Python 구문, 소스 해시와 ZIP 무결성 검사 통과.
- 이 환경에는 실행 가능한 브라우저가 없어 실제 화면 배치·터치·네이티브 키보드/포커스 동작과 실제 GPU 렌더링은 직접 검증하지 못했습니다. 기존 브라우저 검사 스크립트는 포함되어 있으나 이번 실행 결과로 계산하지 않았습니다.

브라우저 최종 확인 시 1440×900 / 1024×768 / 390×844 / 낮은 가로 화면에서 도구 숨김·그룹 펼침·편집기 높이 조절을 확인하세요. 편집→Run→실패→수정, 패스 왕복, Pack 저장/불러오기, 모바일 패널 열기→편집기 열기도 확인 대상입니다. 자동 검증 통과를 시각적 완성도나 모든 브라우저에서의 보장으로 해석하지 않습니다.
