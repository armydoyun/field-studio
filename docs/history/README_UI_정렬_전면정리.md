# HTML·CSS 전면 정리 — 간격과 정렬

2026-10-15. 이번 실행 소스 변경은 `index.html`과 `style.css`뿐입니다. `js/*.js`는 직전 버전과 바이트 단위로 동일합니다.

## 분석 결과

이전 602줄 CSS에는 초기 UI, Graphite 수정, 작업공간 수정, 모달/여백 수정이 차례로 누적되어 있었습니다. 같은 요소의 크기·색상·padding이 여러 위치에서 결정되고 일부 작은 화면 규칙은 뒤의 기본 규칙에 다시 덮였습니다. 부분 보정이 반복되는 원인이어서 기본 스타일을 컴포넌트별로 다시 구성하고 반응형 변경을 뒤로 모았습니다.

## 구체적인 정리

| 영역 | 문제와 변경 |
| --- | --- |
| 패널 기준선 | 헤더/탭/본문/검색/푸터의 좌우 기본 여백을 20px로 정리. 서로 달랐던 검색창·본문 여백 제거 |
| 버튼 정렬 | 기본 버튼을 inline-flex + 양방향 중앙 정렬로 통일. 아이콘 버튼은 정사각형과 padding 0을 명시. 목록/진단 버튼만 왼쪽 정렬 |
| 체크박스 | 브라우저 기본 margin 제거, 라벨과 중앙 정렬. bool 손잡이는 track의 50%를 기준으로 수직 중앙 배치 |
| FPS 단위 | 고정 top 좌표를 제거. 숫자 입력과 FPS 단위를 Grid의 두 칸에 분리하여 네이티브 증감 버튼과 겹치지 않음 |
| 검색창 | 단축키 배지를 별도 Grid 칸에 배치. 브라우저 기본 검색 지우기 버튼을 덮지 않도록 구성 |
| 폼 | 파라미터 생성 폼은 Grid gap 16px, 내부 필드 margin 0. 라벨/입력/설명의 간격을 구분 |
| 카드 | 파라미터 카드 padding 14px, 카드 사이 12px. 긴 이름과 타입 배지는 부모의 flex gap으로 배치하며 줄바꿈 시 불필요한 왼쪽 margin이 생기지 않음 |
| 모달 | 헤더의 마크/제목/닫기를 36px 기준으로 정렬. 확인·취소는 같은 폭의 Grid 칸과 높이 40px로 구성해 글자/단축키를 중앙 정렬 |
| 편집기 헤더 | 패스 탭과 창 조작 버튼을 별도 HTML 그룹으로 구성. 좁은 화면에서 그룹 단위로 줄바꿈 |
| 작업 툴바 | 패스 도구와 실행 도구를 별도 정렬. 오른쪽 실행 도구의 기준선을 유지하고 체크박스·select·버튼은 수직 중앙 정렬 |
| 긴 텍스트 | 긴 패스 탭/코드 제목과 긴 통계 숫자는 영역을 밀지 않도록 말줄임 처리. 오류/설명/이미지 이름은 줄바꿈 허용 |
| 도구 본문 | 상단 12px·좌우 14px·하단 16px와 gap 12px 유지. 첫 카드부터 동일한 여백 적용 |
| 미리보기 HUD | 출력 정보와 FPS/해상도/프레임을 같은 HTML footer 안에 배치. 독립된 absolute 좌표를 없애고 공간이 부족하면 줄바꿈 |
| 미리보기 크기 | 화면 전체가 아니라 실제 preview 크기를 기준으로 container query 적용. 미리보기가 낮으면 통계/힌트를 숨겨 툴바와 겹침을 방지 |
| 코드 레이어 | textarea·강조 pre·줄 번호의 글꼴/행간/상단 padding 유지. textarea와 강조 pre에 같은 stable scrollbar gutter를 지정 |
| 도움말 | 고정 헤더와 내부 스크롤 본문을 분리. 제목/문단/단축키 행의 간격을 재구성 |
| 전체 색/타입 | 한 번 정의한 표면·경계·텍스트·강조 토큰을 사용. 외부 폰트와 과거의 장식 효과, 불필요한 애니메이션 규칙 제거 |

픽셀 값만 덧붙이지 않고 오래된 덮어쓰기 구조를 제거했습니다. 기본 스타일과 반응형 스타일은 의도적으로 구분합니다. 같은 기본 규칙의 속성을 반복해서 재정의하지 않습니다. 입력·프로젝트·재생·모달 Enter 로직과 저장 포맷은 변경하지 않았습니다.

- `tests/ui-geometry-regression.js`: CSS를 선택자/선언/미디어·컨테이너 범위로 읽어 같은 범위의 동일 선택자/속성 중복을 검사합니다. 중앙 정렬, FPS/검색 배치, 모달 Grid, 헤더 그룹, HUD 공동 배치, 코드 gutter 계약도 확인합니다.
- 기존 동작·모달·패스·파일·복구 회귀 검사와 함께 Node 20개 스위트 통과.
- HTML 중첩, 고유 ID 171개, AMD 연결, JavaScript/Python 구문, 소스 해시와 ZIP 무결성 확인.
- 모든 실행 JavaScript가 직전 버전과 동일한지 별도로 비교했습니다.

이번에는 로컬 서버를 열고 별도 브라우저에서도 접속을 시도했으나, `ERR_CONNECTION_REFUSED`로 화면을 열지 못했습니다. 따라서 실제 브라우저 스크린샷·네이티브 폰트의 픽셀 배치·브라우저별 시각 결과는 검증하지 못했습니다. 정적 계약과 동작 검사 통과를 픽셀 수준의 보장으로 표현하지 않습니다.

최종 화면 확인은 기본 뷰포트, 편집기, 파라미터 추가 폼, Ray 파라미터, 패스 연결/이미지/픽셀 그룹, 입력 모달과 확인 모달, 도움말을 대상으로 해야 합니다. 특히 데스크톱·좁은 창·낮은 preview에서 줄바꿈과 스크롤을 확인하세요. 기존 CSS의 :has와 이번 container query를 지원하는 현대 브라우저를 전제로 합니다.
