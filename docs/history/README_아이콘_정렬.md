# 아이콘 정렬 보정 · 2026-10-15

파라미터 삭제 버튼은 SVG가 아니라 글꼴의 × 문자였다. flex의 중앙 정렬은 글자의 line box를 맞추므로 글꼴마다 획의 중심이 달라질 수 있었다.

- 파라미터·이미지 삭제, 패널·편집기·검색·모달·도움말 닫기를 동일한 SVG 마스크로 통일했다.
- 아이콘은 24×24 viewBox 안에 그리며 16×16 CSS 상자에서 중앙에 배치한다. 닫기 X는 (12,12)를 기준으로 대칭이다. currentColor를 사용해 기존 hover·disabled 색상을 따른다.
- 검색 이전/다음은 30px 정사각형, 패스 순서 버튼은 32px 정사각형, 이미지 삭제는 28px 정사각형으로 고정했다. 내부 padding은 0이다.
- 재생·최종 Image·도움말·코드·집중 모드 아이콘과 disclosure의 +/−도 글꼴 의존성을 제거했다. 재생/집중 모드의 도형은 aria-pressed에 따라 바뀌므로 상태 갱신이 문자 아이콘을 복원하지 않는다.
- 기존 툴바 SVG의 획 두께와 끝/모서리를 통일하고 장식 SVG를 접근성 트리에서 제외했다. 검색 SVG의 전체 도형 범위도 중앙으로 보정했다.
- 아이콘 버튼의 aria-label은 유지하고 이미지 삭제·검색 이동에도 명시했다. 텍스트 라벨이 있는 버튼의 일반 문장과 해상도의 곱셈 기호는 그대로 유지한다.

외부 라이브러리·폰트·이미지 파일·아이콘 JavaScript 모듈을 추가하지 않았다. 마스크 데이터는 CSS 안에 포함되며 동일 아이콘을 공유한다. 실행 파일은 기존 13개, AMD 모듈은 10개다.

## 검증

20개 Node 회귀 검증 스위트 통과. 파라미터 삭제 아이콘의 접근 가능한 이름과 실제 삭제 동작, 아이콘 버튼의 글꼴 문자 제거, 고정 도형 크기와 마스크 위치, 상태별 아이콘, 정사각형 버튼 및 기존 CSS/HTML 구조 검증을 포함한다. JavaScript 전체 구문 검사와 Python 구문 검사 통과. SHA-256 및 ZIP 무결성 확인.

검증은 정적 CSS/HTML 계약과 모의 DOM/WebGL에서 실제 모듈을 실행한 결과다. 현재 환경에서 실제 브라우저 스크린샷을 확보하지 못했으므로 OS·배율별 픽셀 단위의 완벽한 시각 검증을 주장하지 않는다.
