# 커스텀 모달 — Matte UI

브라우저 기본 `prompt()`/`confirm()`을 사용하지 않고, `index.html`에 있는 단일 `<dialog id="studioPromptDialog">`을 `js/studio.js`에서 관리합니다. `js/code-editor.js`는 입력 콜백을 주입받으므로 새 실행 모듈이나 외부 라이브러리가 필요하지 않습니다.

- **입력 모달:** 편집기의 `Go to line` / `Ctrl+G`. 현재 줄을 기본값으로 표시하고, 1~마지막 줄 범위에서만 확인할 수 있습니다.
- **확인 모달:** 이미지 삭제, 다른 GLSL·프로젝트·예제 가져오기, 프로젝트 초기화. Undo/Redo는 편집 이력을 즉시 이동하므로 확인 모달이 필요하지 않다.
- **조작:** Enter는 확인, Esc·취소·닫기·배경 클릭은 취소. 입력 시 포커스가 모달에 머무르며 닫힌 후 원래 위치로 돌아옵니다.
- **안전장치:** 취소 시 원본 프로젝트를 유지합니다. 위험한 작업은 붉은 계열의 절제된 강조색으로 구분하고, 미적용 코드가 있을 때 확인 대기 동안 자동 컴파일 타이머를 잠시 중단합니다. 연속 확인창도 지원합니다.

동기적 동작을 유지할 수 있는 작업(미적용 변경사항이 없는 예제 적용 등)은 기존처럼 즉시 반환하며, 사용자의 확인을 기다려야 할 때는 Promise를 반환할 수 있습니다. 외부 JavaScript에서 이런 API 결과를 기다려야 한다면 `await`를 사용하세요.

## 수정 위치

- `index.html`: 모달 마크업
- `style.css`: 매트 차콜·슬레이트 블루 테마와 위험 확인 색상
- `js/studio.js`: 모달 소유 및 공통 확인 로직
- `js/code-editor.js`: 줄 번호 입력 연결
- `tests/custom-modal-regression.js`: 구조·구문 검사 (Node.js 선택 사항)

기존 셰이더·버퍼·GPU 프로그램은 변경하지 않았습니다. 브라우저의 네이티브 `<dialog>`를 지원해야 합니다.
