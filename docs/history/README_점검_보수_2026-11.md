# 점검 · 보수 (2026-11-17)

기능 개발을 잠시 멈추고, 있는 기능을 실제 앱에서 하나씩 써 보며 고장 · 어긋난 동작을 찾아 고쳤다.
고친 것마다 고치기 전 코드에서 실패하는 회귀 검사를 남겼다.

## 1단계 — 검증 기반

- **py 묶음을 이 환경에서도 실행:** 시스템 Python에 pip로 설치할 수 없는 환경이라 가상 환경을 만들고 `PYTHON=<venv>/bin/python`으로
  돌렸다(브라우저는 `CHROMIUM_PATH`의 것). 13개 모두 통과 — 로컬과 CI가 같은 범위를 본다.
- **커버리지 측정 `node tests/run.mjs browser --coverage`** (`tests/helpers/coverage.mjs`): browser 묶음이 `js/` 파일을 얼마나
  지나가는지, **한 번도 불리지 않은 이름 있는 함수**가 무엇인지 `test-results/coverage/summary.txt`에 남긴다.
  이 목록을 2단계 점검 순서로 썼다(테스트가 한 번도 부르지 않은 명령 · 메뉴 · 경로부터).
