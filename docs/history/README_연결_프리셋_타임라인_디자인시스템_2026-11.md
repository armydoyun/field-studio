# 파라미터 연결 · 프리셋 · 키프레임 타임라인 · 디자인 시스템 (2026-11-13 ~ 11-15)

11월 13~15일에 들어온 큰 기능과 그 뒤 정리를 한곳에 모은 기록입니다. 자세한 이유는 각 커밋 메시지에 있습니다.

## 파라미터 연결 (`js/links.js` · `js/link-sheet.js` · `js/midi-input.js`)

- 파라미터 값을 **소리**(저음 · 중음 · 고음 · 음량) · **MIDI CC** · **흔들기(LFO)** · **키프레임**이 정하게 합니다.
- 연결 시트는 "소스 → 입력 → 출력(범위 · 뒤집기) → 반응(부드럽게) → 결과" 순서로 위에서 아래로 읽습니다.
- MIDI는 처음 쓸 때 권한을 받고, '학습' 버튼으로 다음에 움직인 컨트롤러를 잡습니다.
- 키프레임의 시간 기준이 '반복'이면 끝과 처음을 이을지 고릅니다(기본은 이전과 같은 '끝 값 유지').

## 파라미터 프리셋 (`js/presets.js`)

- 값 묶음을 이름 붙여 저장하고 즉시 또는 몇 초에 걸쳐 전환합니다. 위젯 종류에 맞게 섞습니다
  (실수 · 벡터 · 행렬 · 색은 선형, `@dir`은 섞은 뒤 길이 1, `@angle`은 가까운 쪽으로).
- 적용 전에 지금 코드의 파라미터와 호환되는지 검사하고, 적용을 되돌릴 수 있게 기록합니다.
- 덮어쓰기는 ⋯ 메뉴 · 확인 · 되돌리기를 거칩니다.

## 키프레임 타임라인 (`js/timeline.js`)

- 미리보기 아래 도크. 재생 위치 이동 · 키 끌기 · 추가 · 삭제 · 다중 선택 · 확대(Ctrl+휠) · 되돌리기.
- 시간 스냅과 값 스냅을 따로 고르고, '자석'은 재생선 · 다른 키 · 범위 끝에 6px 안에서 붙습니다(Alt로 모두 끔).
  붙는 동안 점선과 대상 강조로 무엇에 붙었는지 보여 줍니다.
- 높이 경계를 끝까지 줄여 놓으면 숨깁니다('놓으면 숨김').

## 파라미터 편집 (`js/parameter-tools.js` · `js/value-editor.js` · `js/matrix-control.js`)

- 실수 · 벡터는 하나의 정밀 입력 대화상자를 씁니다. 적용 전까지 렌더러에 닿지 않습니다.
- 행렬은 행/열로 보여 주고 값은 GLSL 열 우선 순서로 보관합니다(정밀도 유지).
- 파라미터 탭 위 한 줄 도구막대 · '변경만 보기' · '바꾸기 전과 비교'.
- 선언은 코드가 가집니다. 파라미터 선언을 자동으로 삽입하지 않고, 선언 없이 쓰던 파라미터를 지우면 묻지 않고 지운 뒤 오류는 편집기에 표시합니다.

## 디자인 시스템 (`css/` · `js/ui-kit.js` · `js/custom-select.js`)

- `style.css` 한 파일(190KB)을 `css/` 아래 기능별 파일로 나눴습니다. `index.html`의 링크 순서가 빌드 · 해시 · 테스트의 단일 출처입니다.
- 토큰(`css/tokens.css`) · 공통 컴포넌트(`ui-*`, `css/components/`) · `js/ui-kit.js`로 화면 전체를 다시 짰습니다.
  기능 CSS에는 배치만 남습니다. 규칙은 `docs/DESIGN_SYSTEM.md`.
- 드롭다운은 공용 모양(`custom-select.js`)이지만 값 · 이벤트의 출처는 원래 `<select>`입니다.
- 아이콘은 SVG만 씁니다(이모지 없음).

## 도움말 (`js/guide.js` · `js/guide-tours.js` · `js/context-menu.js`)

- UI 둘러보기를 주제별 둘러보기로 나눴고, 가이드 목차를 접히는 분류로 정리했습니다.
- 앱 전체에 커스텀 우클릭 메뉴(Shift+우클릭은 브라우저 기본).

## 검사

- `tests/design-system-regression.js`: 쓰는 토큰이 정의돼 있고, `ui-*`는 컴포넌트 파일에만 있고, 기능 CSS가 모양을 다시 칠하지 않는지.
- `tests/spacing-browser-regression.js`: 실제 앱의 여러 화면 상태에서 조작 · 선 · 잘림 사이 거리를 잽니다(규칙은 디자인 문서 4장).
- 프리셋 전환 테스트의 간헐 실패(부동소수점 반올림으로 한 값이 먼저 끝나는 경우)는 모든 값을 기다리도록 고쳤습니다.
