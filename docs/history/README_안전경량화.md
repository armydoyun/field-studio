# 경량화 최종 검토 — 기능 유지

기준: Undo 커서 복원 버전 (13개 실행 필수 파일)

## 수정 범위
- `js/studio.js`: DOM 노드 생성의 중복 호출을 `element(tag)` 한 곳으로 통일. 기존 이벤트 및 프로젝트 처리 변경 없음.
- `js/ui.js`: Uniform UI 구성의 반복 `document.createElement`를 같은 형태의 작은 팩토리로 통일.
- `style.css`: CSS 선언과 선택자의 순서는 **그대로 유지**하고, 불필요한 구분 공백/서식만 정리. 모든 미디어 쿼리·의사 클래스·중요도 선언 유지.
- 그 밖의 10개 실행 필수 파일: **바이트 단위 원본 유지**. HTML, Shader, 렌더러, 패스 관리자 등 무수정.

## 검증
- 모든 JS: Node `--check` 통과.
- CSS: 선언·선택자·미디어쿼리·순서 **492개 항목 완전 일치** (원본과 파서 기반 비교).
- Chromium CSS: 너비 1440/920/600/390px에서 전체 DOM 계산된 스타일의 값 전수 비교 통과.
- Undo/Redo 브라우저 회귀 검사: 컴파일 실패, 타이핑 그룹, redo, 선택 범위, 스크롤·커서 복구 모두 통과.
- Node 회귀: 구조 35개, Pack 설정 9개, 샘플링, 텍스처, 커스텀 모달, UI Matte, 기본 GLSL 템플릿 통과.
- 실제 GPU 드라이버 GLSL 렌더링은 이 작업에서 별도 실행되지 않음.

### 의도적으로 하지 않은 압축
JS 변수명 난독화, 전체 Minify, 리소스 수명·에러 처리 축소, HTML ID 수정 등은 필사 가독성 및 기능 안정성을 위해 제외.
