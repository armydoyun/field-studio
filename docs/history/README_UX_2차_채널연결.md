# UX 2차: 채널 연결 이해와 이미지 목적지 · 2026-10-15

## 변경

- 입력 채널 바로 아래에 원본 이름, 프레임 종류, 읽는 데이터의 의미를 표시한다. 선택 상자와 설명은 aria-describedby로 연결했다.
- current는 이번 프레임에 앞서 실행된 버퍼 결과, previous는 지난 프레임에 저장된 버퍼 결과로 설명한다. 자기 자신이나 뒤에서 실행되는 버퍼의 current는 이유를 표시한 비활성 옵션으로 보여준다. previous는 선택 가능하다. 공통 제한 설명은 네 채널 아래 한 번만 표시한다. Image는 모든 버퍼 실행 이후 그려지므로 모든 버퍼의 current/previous를 선택할 수 있다.
- 패스 연결 목록은 채널 번호/입력 원본/프레임 종류를 나누어 표시하고 이미지에는 내부 ID 대신 파일명을 사용한다. 채널 번호순으로 정렬하며 카드 클릭으로 패스를 편집하는 기존 동작은 유지한다.
- 자동 적용을 꺼도 연결 목록과 설명은 편집 중인 구성에 맞춰 즉시 갱신한다. 실행 반영 대기 여부를 별도로 표시하여 실제 GPU 연결과 혼동하지 않게 했다. 채널 선택 상자를 재생성하지 않으므로 조작 중 포커스를 유지한다.
- 이미지 연결 버튼은 ‘Buffer B · iChannel2에 연결’처럼 실제 목적지를 표시한다. 빈 채널이 없으면 비활성화하고 먼저 연결을 해제해야 한다고 안내한다. 패스 전환/채널 변경/되돌리기/연결 실패 복구 때 목적지를 갱신하며 기존 입력은 덮어쓰지 않는다. 접근성 이름에도 파일명과 목적지를 포함했다.
- 이미지 카드의 이름·닫기·연결·샘플링 제어를 grid로 정리했다. 닫기 버튼은 28px 정사각형으로 유지하고 긴 연결 문구는 별도 전체 폭 행에 표시한다. 이전의 모든 이미지 버튼에 적용되던 28px 고정 폭도 닫기 버튼만 대상으로 제한했다.

실행 변경은 index.html/style.css/js/studio.js 안에서 처리했다. 새 외부 의존성·실행 모듈을 추가하지 않았다. 프레임 의미/이미지 이름 해석과 빈 채널 탐색은 기존 모듈 내부에서 공유한다.

## 검증

새 `tests/channel-ux-regression.js` 14개 동작 검증 통과. 연결 제한, 설명 연결성, auto on/off, 조작 중 포커스 유지, 이미지 파일명 표시, 채널 번호순 표시, 목적지 갱신, 가득 찬 채널/해제, 덮어쓰기 방지, Undo, 패스 이동, 연결 실패 복구를 확인했다.
기존 UX 1차 16개 검증과 나머지 20개 회귀 스위트 통과. CSS 계약 검사에 설명/목록/이미지 연결 버튼의 정렬 검증을 추가했다. 전체 JavaScript와 Python 구문 검사, SHA-256 및 ZIP 무결성 확인.
실제 브라우저 스크린샷을 확보하지 못했으므로 검증 범위는 정적 HTML/CSS와 모의 DOM/WebGL에서의 실제 모듈 동작이다.
