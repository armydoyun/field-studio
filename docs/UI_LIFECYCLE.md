# UI 자원 수명과 종료

각 UI는 생성한 이벤트·관찰자·타이머·프레임·창을 같은 소유자에서 정리한다.
`dispose()`는 반복 호출해도 안전하게 처리하고, 종료한 인스턴스의 비동기 완료가 UI를 다시 만들지 않게 한다.

| 소유자 | 생성·해제 범위 |
|---|---|
| `popout.js` | 메인 입력 이벤트, 분리 창 이벤트, HUD 관찰자, 실패 안내 타이머. 닫을 때 원본 캔버스·도구·모달 복원 |
| `context-menu.js` | 등록 취소 시 해당 공급자의 열린 메뉴 정리. 문서 연결 해제/창 종료 시 문서 이벤트 해제 |
| `app-menus.js` | 앱 메뉴 공급자와 새 분리 문서 연결을 자체 AbortController로 관리 |
| `menu-bar.js` | 키 이벤트와 비동기 최근 프로젝트 조회. 종료·닫기로 취소된 조회는 메뉴를 다시 만들지 않음 |
| `custom-select.js` | 문서마다 관찰자·이벤트 소유. 문서 종료 시 구독 해제, 필드 분리 시 원본 속성·프로퍼티 복원 |
| `theme.js` | 버튼·테마 선택·시스템 테마 변경 구독 해제 |
| `gallery.js` | 첫 방문 안내 타이머, 미리보기 시작 프레임, 열린 모달과 미리보기 작업 정리 |
| `guide.js` | 포커스/복사 안내 타이머, 투어 배치 프레임·추적 루프, 관찰자·모달 정리 |
| `snippet-preview.js` | 미리보기 대기열·컴파일 중단·GPU 컨텍스트 정리. 종료 중 새 관찰자를 만들지 않음 |

## 분리 창

창을 여는 중의 중복 `open()`은 같은 요청을 기다린다. `close()`나 `dispose()` 후 요청이 완료되면
늦게 열린 창을 닫고, 원본 DOM을 이동하거나 대체 팝업을 열지 않는다.
오래된 요청이 새로 연 창을 되돌리지 않도록 요청 세대를 구분한다.

분리 문서에서의 메뉴 바·전체화면·팝오버 구독은 그 문서의 `pagehide`에서 해제한다.
입력 모듈의 기존 분리 창 AbortController도 복귀할 때 해제한다.
선택 상자는 원본과 보이는 버튼을 다시 삽입할 때 재사용하며, 분리 상태에서는 이벤트와 프로퍼티 훅을 해제한다.

## 앱 종료와 시작 실패

`main.js`는 취소 가능한 `beforeunload`에서 앱을 종료하지 않는다.
최종 `pagehide`에서 분리 창을 먼저 복원하고, 런타임과 기본 UI를 정리한 뒤 공개 API 참조를 제거한다.
`pagehide.persisted`가 참이면 뒤로 가기 캐시에서 같은 인스턴스로 복귀할 수 있도록 유지한다.

렌더러 시작 실패는 런타임만 정리하여 테마·배치 등 기본 UI를 유지한다.
초기 텍스처 복구를 기다리는 중 종료되면, 기다리던 요청이 끝나도 편집기·갤러리 등 후속 UI를 만들지 않는다.

## 검사

- `popout-regression.js`: 중복 요청, 늦은 완료/실패, 종료 후 API, 반복 해제, 안내 타이머.
- `resource-lifecycle-browser-regression.js`: 테마/메뉴 반복 연결·해제, 원본 필드 복원, 관찰자 수, 가이드/갤러리 예약 작업, 종료 경로.
- `window-lifecycle-browser-regression.py`: 실제 창 세 차례 분리·복귀 후 앱 이벤트 0개와 관찰자 수 복원, 초기화 대기 중 종료, 렌더러 시작 실패.

이벤트 검사는 Playwright가 주입하는 입력 검사 핸들러를 구분해 앱이 소유한 구독만 센다.
