## 점검 · 보수(2026-11-17)에서 넘긴 것

- **큰 파일 나누기:** `studio.js`(약 3,100줄) · `renderer.js` · `guide.js` · `ui.js` · `cm-editor.js`(각 1,900~2,100줄).
  동작을 바꾸지 않는 이동만으로 나누되, 한 번에 한 덩어리씩(예: `studio.js`의 패스 관리 · 파일 입출력) 하고 커버리지(`--coverage`)로
  옮긴 코드가 테스트로 지나가는지 확인한다.
- **패스 순서 바꾸기의 되돌림:** 버퍼를 위로 옮기면 `current` 참조가 `previous`로 바뀌는데(안내는 한다), 다시 아래로 옮겨도 `current`로
  돌아가지 않는다. 지금은 Ctrl+Z로만 되돌린다. 원래 참조를 기억해 두었다가 순서가 다시 맞으면 돌려놓을지 검토.
- **`main` · `mainImage` 이름 바꾸기:** F2로 진입점 함수 이름도 바꿀 수 있어 바꾸면 셰이더가 실행되지 않는다. 경고를 더할지 검토.
- **py 묶음 실행 환경:** 시스템 Python에 설치할 수 없는 환경에서는 가상 환경 + `PYTHON`이 필요하다. 클라우드 작업 환경의 설정 스크립트로
  미리 준비해 둘지 검토.
- **커버리지에 py 묶음 포함:** 지금 `--coverage`는 browser 묶음만 센다. 편집기 키 동작 대부분은 py 묶음(`cm-editor-browser-regression.py`)이
  확인하므로 그쪽도 합치면 '안 불린 함수' 목록이 더 정확해진다.
