# 프로젝트 파라미터 통합 및 작업 흐름 개선

2026-10-15. 이 문서가 Required/Custom, 설정 초기화, 최신 UI 동작에 대한 기준입니다. 다른 README는 이전 버전의 변경 이력입니다.

## 구조

- Renderer의 Required Map, 등록 API, 삭제 금지 분기, 목록 병합을 제거했습니다.
- `defineUniform`, `setUniform`, `removeUniform`, `getUserUniforms`, `setUserUniforms`가 하나의 Map을 사용합니다. `getUniforms`는 같은 조회 함수의 호환 별칭입니다.
- `defineRequiredUniform`, `getRequiredUniforms`, 항목의 `required` 속성은 제거되었습니다. 외부 코드가 이 API를 사용했다면 `defineUniform`/`getUserUniforms`로 변경해야 합니다.
- uTime/uResolution/uMouse/iChannel 등의 내장 변수는 계속 Renderer가 공급하고 이름을 예약합니다. 프로젝트 파라미터와 섞지 않습니다.
- 새 localStorage/Pack 설정은 `required`를 저장하지 않습니다. 기존 `required.uCameraOrbit`은 프로젝트 파라미터로 이관합니다. 같은 이름의 기존 파라미터가 우선하며, 슬롯 부족이나 잘못된 값이면 원본 저장 데이터를 보존합니다.
- 기존 확장에서 추가했던 다른 Required 값은 타입 정보가 없으므로 자동 이관하지 않습니다. 기존 프로그램이 기본 제공한 카메라만 명시적으로 이관합니다.

## UI와 UX

| 작업 | 바뀐 동작 |
| --- | --- |
| 파라미터 찾기 | Required/Custom 두 목록을 하나로 통합. 총 개수와 64개 한도, 검색 결과 수 표시 |
| 추가 | 목록 위의 접힌 추가 폼. 성공하면 검색을 비워 새 항목을 표시하고 추가 버튼으로 포커스 복귀 |
| 숫자/벡터 편집 | 잘못된 값을 적용하지 않고 이전 값 복원. 오류 안내와 입력 오류 표시 |
| 벡터 편집 | Renderer의 현재 값을 읽은 뒤 해당 성분만 변경. 카메라/외부 JS가 바꾼 다른 성분을 보존 |
| 슬라이더 | 숫자 입력과 양방향 동기화. 슬라이더 뒤 잘못된 숫자를 입력해도 마지막 적용 값 복원 |
| 타입 변경 | 숨겨진 숫자 슬라이더 옵션은 bool/벡터 추가에 간섭하지 않음 |
| 삭제 | 성공 후 최근 삭제 1개를 되돌리는 버튼 제공. 현재 값과 범위 옵션까지 복원. 삭제/복원 컴파일 실패 시 기존 상태 유지 |
| Starter | 코드·버퍼·파라미터 교체 안내. 전용 파라미터 수/Undo 안내. 전환 후 검색 및 이전 프로젝트의 삭제 복원 상태 초기화 |
| 편집기 → 파라미터 | Parameters 버튼으로 편집기를 닫고 파라미터 패널을 열어 검색창에 포커스 |
| 내장 변수 | 접힌 참조 영역에서 이름/타입/용도를 확인. 등록할 필요 없음 |
| 카메라 | vec3 uCameraOrbit 유무에 따라 활성/비활성 상태 표시, 비활성일 때 Reset 버튼 사용 불가 |
| 환경설정 초기화 | 렌더링 품질/프레임 제한/기존 호환 렌더 설정/패널 표시만 초기화. 프로젝트 파라미터와 코드는 보존하고 자동 저장 |

파라미터 삭제 되돌리기는 최근 1개를 위한 별도 동작입니다. 코드/Starter의 Undo 기록과 합치지 않습니다. Starter 전환이나 Pack 설정 적용, 파라미터 구성이 바뀌는 Undo/Redo, 새 파라미터 추가 시 삭제 복원 상태를 비웁니다. 일반 값 편집은 별도 Undo 기록을 만들지 않습니다.

## 파일과 규모

수정한 실행 파일은 `index.html`, `style.css`, `js/renderer.js`, `js/settings.js`, `js/ui.js`, `js/studio.js`입니다. 새 실행 모듈/라이브러리는 추가하지 않았습니다. 실행 파일 13개 기준 UTF-8 총 크기는 246,188 → 247,876바이트이며 총 줄 수는 3,003 → 3,010줄입니다. Required 경로를 줄인 여유로 입력 검증과 삭제 복원을 추가했습니다.

## 검증

- `node tests/parameter-ui-regression.js`: 실제 UI 모듈과 모의 DOM/WebGL을 이용한 12개 검사. 빈 목록, 숨겨진 범위 옵션, 예약 이름, 외부 벡터 변경 보존, 빈 벡터, 슬라이더/정수 오류, 삭제 복원/실패, 프로젝트 전환, 패널 연결, 최신 값 복원, 잘못된 쉼표 입력.
- Starter 소유권 20개, 심층 로직 34개, 일반 로직 19개, 구조/API 44개 및 기존 Node 검사 통과.
- `runtime-integrity.js`: 실행 파일 SHA-256, AMD 의존성/인자/순환, HTML ID 연결 검증.
- 실제 브라우저 화면 배치와 실제 WebGL 드라이버 렌더링은 이 환경에서 실행하지 못했습니다. `index.html`을 브라우저에서 열어 패널/편집기 전환, 좁은 화면 배치, 실제 GLSL 컴파일 오류 시 파라미터 삭제 복구를 확인해야 합니다.
