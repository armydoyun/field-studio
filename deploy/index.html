버퍼 · 데이터

            
+ Buffer로 패스를 추가하고 iChannel0~3에서 Texture 또는 Buffer를 연결합니다. current는 먼저 실행된 패스, previous는 직전 프레임의 결과입니다. Auto는 코드 변경 시 자동 적용, Pause는 재생 정지, Reset은 프레임/피드백 초기화, Undo/Redo는 컴파일 실패를 포함한 편집 이력을 되돌립니다. 연속 타이핑은 묶어서 저장하며, 편집기에서 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z를 사용할 수 있습니다.
